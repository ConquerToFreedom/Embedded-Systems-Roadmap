# CAN-Based ECU Simulation (Planned)

**Status: Not started — final major project in the roadmap.**

The capstone project: a CAN-based automotive ECU simulation combining
everything from earlier phases — register-level drivers, FreeRTOS tasks,
and CAN protocol communication — into one integrated system.

Depends on `03_communication_protocols` (CAN) and `04_rtos_systems` being done first.
